# Smart Museum Artifact Conservation System

## Assignment
This repository contains the analysis for the Smart Museum Artifact Conservation System.

### Tasks
- **Task 1:** Identify at least 12 operations performed by the system.
- **Task 2:** Create a complete operation schema for each identified operation.

## Repository Structure

- `Task-1-Operations.md` — Identified system operations.
- `Task-2-Operation-Schemas.md` — Complete schemas for the operations.
- `State-Machine-Overview.md` — Main system states and important transitions.

## System Objective

The system continuously monitors the conservation chamber and protects historical artifacts by checking environmental conditions, responding to abnormal temperature/humidity, vibration, door status, sensor failures, and power failures.

The system must verify recovery conditions before returning to normal conservation operation.
